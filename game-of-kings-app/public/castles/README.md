Castle image folder convention

Put owned or approved castle images here when you want them bundled with the site.

Recommended structure:

public/castles/winterfell/exterior-1.jpg
public/castles/winterfell/interior-1.jpg
public/castles/winterfell/banner-1.png
public/castles/winterfell/map-1.jpg
public/castles/winterfell/artwork-1.jpg

Use the castle id from the map data, such as:
winterfell, kings-landing, dragonstone, casterly-rock, highgarden, storms-end, sunspear.

Avoid dropping random web images here unless you have permission to use them.
